# Aplikasi Order Barang (Web Kasir & Order Management)

Aplikasi web berbasis Python untuk manajemen order barang, kasir, inventori stok, dan resep bahan.

## Fitur
- Manajemen transaksi penjualan / kasir
- Manajemen order barang & purchase order
- Kontrol stok inventori & resep menu
- Master kategori & pengaturan sistem
- Pencatatan waste / barang rusak

## Cara Menjalankan
1. Pastikan Python 3 sudah terinstal.
2. Jalankan `jalankan.bat` atau via terminal:
   ```bash
   python app.py
   ```
3. Buka browser di alamat yang muncul di terminal (misalnya `http://localhost:5000` atau port yang dikonfigurasi).
